# Standing option — specialized/high-value pivot

Status: **NOTED, NOT ACTIVE**

## The option

If mid-course the business direction needs to shift from "cheap, broad
reach, many small tenants" to "specialized, high-price, few clients" —
e.g. data synthesis work, high-accuracy domain work, project/research
engagements — the War Room structure supports that switch without a
rebuild:

- **Operations** changes mode: from fast Onboarding to a proper project/
  brief intake conversation
- **Development and Audit** keep their existing shape — only the policy
  changes (e.g., permission to use costlier models given higher per-client
  revenue)
- **Project Lead** is the one who calls this switch

## Why this is a standing option, not a plan

Nothing about this should be built now. It is preserved here so that if
the owner decides to switch, nobody has to re-derive from scratch that the
War Room structure already anticipated it.

## What it changes downstream

- `docs/product/PRICING_V1.md` — flat 299 THB no longer applies; revisit
  entirely for a specialized mode
- `docs/product/MODEL_POLICY.md` — higher-tier models become the default
  for a specialized client, not just for onboarding
- Data purchasing (`docs/product/CUSTOMER_SEGMENTS.md`, "Deferred: data
  purchasing") becomes relevant here, not before
