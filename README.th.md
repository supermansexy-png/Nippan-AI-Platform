# Nippan AI Platform — สรุปภาษาไทย

สถานะ: **เฟส A — ทดลองตลาด** (อัปเดต 24 ก.ย. 2569)

เอกสารหลักทั้งหมดเขียนเป็นภาษาอังกฤษเพื่อให้ AI ทุกตัวอ่านได้ตรงกัน ไฟล์นี้คือสรุปภาษาไทยสำหรับเจ้าของโครงการ ถ้าเนื้อหาไม่ตรงกัน **ให้ยึดเอกสารภาษาอังกฤษ** และแก้ไฟล์นี้ตาม

## 1. เราทำอะไร

ให้ร้านค้า/ธุรกิจเล็กเช่าบอท AI ผ่าน LINE ของร้านเอง หรือแชทบนเว็บ ใช้ระบบเดียวกันทำได้หลายแบบ เช่น บอทตอบลูกค้า บอทเลขารับนัด และจะเพิ่มประเภทใหม่ได้เรื่อยๆ

- รับไม่เกิน **30 ร้าน** ในเฟสแรก เพื่อพิสูจน์ว่าตลาดต้องการจริง
- ราคา **299 บาท/บอท/เดือน** ราคาเดียว มีโควตาข้อความ (เริ่มที่ 600 ข้อความ ปรับตามข้อมูลจริง)
- ตั้งค่าบอทด้วยการ **คุยกับ AI** หรือส่งไฟล์/ลิงก์ร้าน ไม่ต้องกรอกฟอร์ม
- ถ้าไปได้ดี ค่อยสร้างระบบใหญ่รองรับ 100+ ร้าน (แบบแปลนเดิมเก็บไว้ใน `docs/future/`)

## 2. กฎเหล็กที่ห้ามละเมิด

1. บอท **ไม่บอกว่าใช้ AI ยี่ห้อไหน** แต่ **ห้ามแกล้งเป็นคน** — ถ้าลูกค้าถามจริงจัง ต้องยอมรับว่าเป็นผู้ช่วยอัตโนมัติ
2. **ห้ามเอาข้อมูลลูกค้าไปฝึกโมเดล** ถ้าไม่ได้รับความยินยอมล่วงหน้าแยกต่างหาก (PDPA)
3. **ข้อมูลแต่ละร้านห้ามปนกัน** ทุกตารางมีรหัสร้านและรหัสบอทกำกับ
4. บอทตอบเรื่องราคา/สต็อก/นโยบาย **จากข้อมูลของร้านเท่านั้น** ไม่แน่ใจให้ส่งต่อเจ้าของร้าน
5. แต่ละร้านใช้ **LINE OA ของร้านเอง** (แพ็กเกจฟรี) — บอทตอบข้อความที่ลูกค้าทักมาก่อน **ฟรีไม่จำกัด** ส่วนข้อความที่บอทเป็นฝ่ายเริ่มส่งเอง (เช่น เตือนนัด) เราจำกัดไว้ **200 ข้อความ/เดือนต่อบอท** (ต่ำกว่าเพดานฟรีของ LINE ที่ 300 เพื่อกันร้านโดนเก็บเงินเอง) ไม่ใช้บัญชี LINE กลางเพราะจะคุมโควตาแยกรายร้านไม่ได้

## 3. ระบบทำงานยังไง (แบบย่อ)

```
ลูกค้าของร้าน → LINE ของร้าน / แชทเว็บ
                     ↓
          n8n (ติดตั้งบนเซิร์ฟเวอร์ของเราเอง)
          ↙                         ↘
  เครื่องมือ MCP                ฐานข้อมูล PostgreSQL
 (ตอบแชท, ความจำ, ตั้งค่า,      ร้าน → บอท → ช่องทาง →
  นับการใช้, แจ้งเตือน, ส่งต่อ)   ลูกค้าของร้าน → บทสนทนา
```

ความจำ 4 ชั้น: บทสนทนาล่าสุด → สรุปย่อ → ความจำระยะยาว → ข้อมูลร้าน (มีวันหมดอายุตาม PDPA)

## 3.1 การเชื่อมต่อแพลตฟอร์มอื่น (ปัจจุบันและอนาคต)

หลักการ: **แกนกลางไม่รู้จักแพลตฟอร์มใดเลย** ทุกแพลตฟอร์มเข้าผ่าน "อะแดปเตอร์" 1 ตัว ที่แปลงเป็นรูปแบบกลางเดียวกัน แพลตฟอร์มใหม่ (รวมถึงตัวที่ยังไม่เกิด) = เขียนอะแดปเตอร์เพิ่ม 1 ตัว ของเดิมไม่ต้องแก้

อะแดปเตอร์มี 3 แบบ: **ช่องทางแชท** (LINE, Facebook, WhatsApp, TikTok, อีเมล…) · **ตัวเชื่อมระบบร้าน** (POS, สต็อก, ปฏิทิน, บัญชี) · **แหล่งเหตุการณ์** (เงินเข้า, มีออร์เดอร์, มีรีวิว)

บอทขอ "ความสามารถ" ไม่ใช่ "แพลตฟอร์ม" — "เช็คสต็อก" ใช้ได้เหมือนกันไม่ว่าร้านใช้ POS ยี่ห้อไหนหรือแค่ Google Sheet

ถ้ายังไม่มีอะแดปเตอร์ ยังมีทางสำรอง: webhook ทั่วไป, node สำเร็จรูปของ n8n, ส่งออกเป็น Google Sheet, MCP server ของผู้ให้บริการ, อีเมล — ร้านจะไม่ได้ยินคำว่า "เชื่อมไม่ได้"

กฎความเสี่ยง: อ่านข้อมูล = L2 · เขียนลงระบบร้าน = L2 + ถามยืนยันลูกค้าก่อน · โพสต์สาธารณะ = L3 เจ้าของอนุมัติทุกโพสต์ · แตะเรื่องเงิน = L3 ไม่อัตโนมัติเต็มตัวในเฟส A/B

สร้างตัวไหนก่อน ขึ้นกับร้านที่ขอจริง ไม่ใช่ไล่สร้างล่วงหน้า — รายละเอียดใน `docs/product/INTEGRATIONS.md`

## 4. ทีม AI (War Room)

| ตำแหน่ง | หน้าที่ |
|---|---|
| Project Lead (ตอนนี้คือคุณ) | ตัดสินใจสุดท้าย อนุมัติ ถือบันทึกการตัดสินใจ |
| Developer / MCP tool builder | สร้าง workflow และเครื่องมือ |
| Auditor | ตรวจก่อนถึงลูกค้าจริง ดูบันทึกมอนิเตอร์ |
| Cost Guard | คุมต้นทุนเท่านั้น |
| Onboarding / Support | ตั้งค่าบอทร้านใหม่ ดูแลร้านเดิม |
| Marketing | เก็บสัญญาณตลาด ร่างการตลาด |
| Model Scout | หา AI ใหม่ที่ถูกกว่า/ดีกว่า เสนอเปลี่ยน |

**บันไดความอิสระ 4 ขั้น** (ทุกตำแหน่ง): ทำมือ → AI ร่างให้คุณตัดสิน → AI ทำเองเรื่องปกติ → AI ทำเอง คุณดูสรุป — ขึ้นขั้นได้เมื่อมีผลงานพิสูจน์ ถ้าทำพลาดร้ายแรงลงทันที 1 ขั้น เริ่มต้น: Operations ขั้น 2 ที่เหลือขั้น 1

| ทบทวนทุกสัปดาห์ ~30 นาที | ปัญหาเล็กแก้รายสัปดาห์ถูก รอรายเดือนแพง |
| จุดตัดสินใจ ไปต่อ/ปรับ/หยุด ตั้งไว้ล่วงหน้า | กันโครงการ "ใกล้เสร็จ" ไปเรื่อยๆ ไม่จบ |

## 5.1 ระเบียบคุม AI (บังคับทุกตัว)

AI ทุกยี่ห้อต้องผ่าน 4 ด่าน: **รับงาน** (เขียนรายงานก่อน ตัดสินว่ารับ/ไม่รับ) → **ทำงาน** (ทำเฉพาะที่สั่ง หยุดเมื่อถึงกฎหยุด) → **ส่งงาน** (มีหลักฐานทุกข้อ ไม่มีหลักฐาน = เสร็จบางส่วน) → **ตรวจรับ** โดย AI คนละตัวหรือคุณ

ปฏิเสธตรงๆ ไม่เสียคะแนน · อ้างว่าเสร็จทั้งที่ไม่เสร็จ = ลดขั้นทันที ทำซ้ำถูกถอดออก

อ่านฉบับเต็ม: `docs/warroom/AI_OPERATING_PROTOCOL.th.md` · ข้อความสั่งงานสำเร็จรูปสำหรับแปะให้ AI: `docs/warroom/START_PROMPT.md`

## 6. ถ้าเกิดปัญหา

- **ระบบล่ม**: บอทตอบข้อความสำรอง "ผู้ช่วยของร้านไม่พร้อมชั่วคราว" และแจ้งคุณทันที
- **บอทตอบผิด**: บอทอิงข้อมูลร้านเท่านั้น ไม่แน่ใจส่งต่อ; สัญญาระบุความรับผิดชอบชัด (ให้ทนายตรวจ)
- **ยกเลิก**: รายเดือน เลิกเมื่อไหร่ก็ได้ คืนเงินเต็มใน 7 วันแรกถ้าใช้ไม่ได้ตามสัญญา เก็บข้อมูล 30 วันแล้วลบ
- **จ่ายเงิน**: โอน/พร้อมเพย์ บันทึกมือ ค้าง 7 วันพักบอท (ไม่ลบ)
- **หาลูกค้า 5–10 รายแรก**: จากคนที่รู้จักโดยตรง ฟรีเดือนแรกแลกความเห็นจริง ยังไม่ยิงโฆษณา
